## About

I am a final-year Information Security student at Van Hien University (VHU) with a primary focus on Web Application Security and Vulnerability Research.

My interests include:

- Web Application Pentesting
- Vulnerability Research
- Open Source Security
- DevSecOps
- Red Team
- Android Security

I actively build vulnerable labs, reproduce CVEs, publish security research, and contribute security advisories to open-source projects.
